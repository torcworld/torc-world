# TORC Batch 63 FIXED

Use this instead of the original Batch 63. Apply after Batch 62.

The original Batch 63 introduced a more complicated active-navigation class construction. This fixed version removes that risk.

- Persistent current-page gold is now applied directly by TorcNav with a simple inline style based on `usePathname`.
- No new global CSS selector is required for the active state.
- Artifacts gets the Submit-family charcoal header with large white Artifacts title and oxblood top rule.
- Search/filter surround gets the lighter resting gold and oxblood frame.
- All other Batch 62 behavior remains intact.

Do not deploy the original Batch 63.
