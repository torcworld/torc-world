# TORC Batch 26 — New corpus analysis pages

Apply after Batch 25.

This patch replaces the generic placeholder content for the latest ten evaluated artifacts with full public TORC analysis pages, using the same analysis architecture as the stronger existing corpus pages:

- governing operation
- why the assigned Operational Order is sufficient
- strongest adjacent/higher alternative and why it fails
- six-dimensional cognitive architecture
- what is structurally exceptional about the artifact

Artifacts covered:
The Magic Mountain; Thus Spoke Zarathustra; The Handmaid’s Tale; Blade Runner; The Truman Show; The Unbearable Lightness of Being; A Clockwork Orange; The Remains of the Day; Solaris; One Hundred Years of Solitude.

The displayed CMS values and dimension profiles use medians across the seven fresh v1.6.3 evaluations. No proprietary protocol gates, thresholds, prompts, or adjudication machinery are exposed.
