# TORC.world terminology update

## New hierarchy
- **TORC** = the complete theory and evaluation framework.
- **TORC Rating** = the compact complete result, e.g. `3b | 800`.
- **Operational Order** = the first coordinate: Level 1, Level 2, 3a, 3b, 3c, G, GΩ, M, etc.
- **Cognitive Magnitude Score (CMS)** = the second coordinate, 0–1000.
- **Cognitive Architecture** = RL, AD, CD, ID, IC, GR.
- **DIP** is removed from public-facing labels in these files so it does not compete with TORC Rating.

Upload the contents of this ZIP to the repository root, preserving paths. This is an overlay update; it does not delete artifacts or replace the whole repository.

Internal implementation field names such as `torc` are intentionally left unchanged.
