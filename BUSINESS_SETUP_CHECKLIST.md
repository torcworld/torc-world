# TORC.world — Business setup checklist

## Phase 1 — Before accepting paid work
- [ ] Decide when TORC crosses from market testing into a recurring commercial service.
- [ ] Before recurring paid work begins, confirm Dutch registration/tax obligations with KVK/Belastingdienst or an adviser.
- [ ] Create a real TORC mailbox (recommended: contact@torc.world).
- [ ] Create a separate submissions alias/address (recommended: submissions@torc.world).
- [ ] Verify torc.world for transactional email delivery.
- [ ] Add a privacy notice covering uploaded unpublished artifacts and retention/deletion.
- [ ] Add terms covering scope, confidentiality, intellectual property, refunds/cancellation, turnaround and publication permission.

## Phase 2 — Submission pipeline
- [ ] Set RESEND_API_KEY in the hosting environment.
- [ ] Set TORC_SUBMISSIONS_EMAIL to the inbox you monitor.
- [ ] Set TORC_SUBMISSIONS_FROM to a verified torc.world sender.
- [ ] Test with a dummy PDF from desktop and mobile.
- [ ] Confirm both: TORC receives the file; customer receives acknowledgement.
- [ ] Decide how long rejected/completed submission files are retained.

## Phase 3 — Payments
- [ ] Create the payment account only when you are ready to trade and have the required business/tax details.
- [ ] Connect the bank account for payouts.
- [ ] Keep submission as a scope request; do not charge automatically on upload.
- [ ] After scope review, send a payment link for the confirmed package/quote.
- [ ] Start evaluation only after payment is confirmed.
- [ ] Generate/store an invoice and payment record for bookkeeping.
- [ ] Define cancellation/refund rules before taking the first payment.

## Phase 4 — Client experience
- [ ] Submission received email.
- [ ] Scope + turnaround + price confirmation.
- [ ] Payment confirmation.
- [ ] Evaluation delivery email.
- [ ] Optional revision re-evaluation offer.
- [ ] Optional testimonial request after delivery.

## Phase 5 — Testimonials
- [ ] Ask: “What did TORC reveal about your work that you had not seen clearly before?”
- [ ] Ask permission separately for website publication.
- [ ] Let client choose attribution: full name / first name + role / anonymous.
- [ ] Never auto-publish submissions or testimonials.
- [ ] Keep only a small number of strong, specific testimonials on the Submit page.

## International structure — later, not as a shortcut
A foreign company can be legitimate, but incorporation abroad by itself does not guarantee foreign-only taxation. Where you live, where the business is actually run, whether it has a Dutch establishment, the legal form, and the relevant tax treaty all matter. If TORC becomes large enough that relocation is worth considering, get cross-border Dutch + destination-country tax advice *before* moving the company or yourself.
