# TORC Batch 48 — Global Warm Ochre Site Ground

Apply after Batch 47.

This fixes the distinction that Batch 47 did not fully reach: the requested color is the **site environment/body**, not the inactive pricing cards.

- Global site background becomes `#ddceb3`.
- This is the same existing light ochre material used by the neutral “Choose a question or leave this open” control family on Submit.
- Inactive pricing cards remain their quieter grey/warm-stone surface.
- Selected pricing remains the stronger gold.
- The Diagnose → Find the gap → Intervene → Test again field remains the stronger gold from Batch 47.
- Existing explicit page surfaces (charcoal, oxblood, paper, book, cards) are not recolored by this patch.

This is a global body-ground trial, so it can also be judged on Theory, Artifacts, Compare, Organizations, and the home page.
